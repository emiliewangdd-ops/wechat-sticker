# 从参考图到动态表情

本文件解决“只有参考图和一句需求，如何得到可复用的高质量四帧动作源”这一问题。它不是把某个角色或某套表情写死，而是规定必须锁定的决策和审核顺序。

## 1. 先建立任务基线

在任务目录保存：

```text
input/       用户参考图和版权/来源说明
prompts/     表情清单、动作分镜和生成记录
masters/     通过审核的文字母版
action-sources/ 通过审核的四帧透明动作源
configs/     只引用批准素材的单张配置
checks/      技术检查、解码帧和联系页
output/      技术通过但仍需审核的工作 GIF
delivery/    最终 240px 上传素材
```

在生成前记录角色不可变特征：物种/人物身份、主要颜色、脸部特征、服饰、比例、线稿/填色风格、透明背景要求和禁止改变的元素。参考图不足以确定的内容要标成待确认，不要让模型自行补成另一种角色。

## 2. 先做表情分镜，再做图片

每个表情至少记录：

- 含义词（后台词）与画面文字（可不同）；
- 起始、变化、峰值、回落四个动作阶段；
- 角色视线、身体重心、四肢/尾巴/耳朵变化和动作线；
- 循环结束时如何自然回到第一帧；
- 小尺寸 240px 下仍必须可读的主体区域。

四帧应有真实的动作差异和清晰的情绪弧线。禁止用同一张图只改变透明度、位置、缩放或轻微抖动来冒充动画。

## 3. 生成和筛选动作源

生成动作源时要求四格保持同一角色、视角、画风、光照、线条和比例；每格都完整包含角色、尾巴、耳朵、四肢、动作线和必要装饰。动作源使用透明背景或可被可靠抠出的背景，不能让角色接触源图边缘。

逐帧筛选时先淘汰：身份漂移、肢体数量变化、文字错字、被裁切、透明边缘光晕、细小残影、动作含义不清和首尾无法循环的候选。不要把失败候选直接交给构建器“试试看”。

## 4. 锁定文字和版式

文字母版与动作分层保存。用一张已批准的参考文字母版锁定字形、描边、黑字可见高度、字距和透明边缘；新文字只改变字形内容，不得自动换成普通系统字体。文字在四帧中像素完全一致。

先确定文字框，再确定动作框和动作锚点。用整组动作的最大可见 alpha 外接框计算一次统一缩放，不能逐帧独立缩放、裁切或居中。任何文字或动作触碰安全边界都应重新生成。

## 5. 审核分层

按以下顺序记录状态：

1. `content_review`：角色、文字、含义词和动作分镜明确；
2. `asset_generation`：已生成候选动作源和文字母版；
3. `visual_review`：人工确认角色一致、动作清楚、循环自然、240px 仍可读；
4. `technical_checks_passed`：构建器和解码检查通过；
5. `ready_for_upload`：最终 240px 主图、缩略图、封面、图标、横幅和 manifest 齐全。

技术通过不能替代视觉批准；视觉批准也不能替代投稿页面的实时规格核对。

## 6. 推荐给图片生成工具的任务模板

```text
保留参考图中的角色身份特征：<逐项列出不可改变特征>。
制作微信动态表情的第 <0/1/2/3> 帧；透明背景，单一角色，保持同一视角、线稿、填色、比例和字形风格。
本帧动作：<动作和情绪>；与前后帧的变化：<变化>。
完整保留耳朵、尾巴、四肢、动作线和装饰，不接触画布边缘，不裁切，不增加新角色或无关文字。
输出用于后续 alpha 检查和统一缩放的动作源，不直接当作最终微信上传图。
```
