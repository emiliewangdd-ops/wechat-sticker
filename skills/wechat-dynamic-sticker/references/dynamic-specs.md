# 动态表情保守基准

这些数值是制作时的保守目标，不是对微信实时后台的承诺。提交前以后台当次提示为准。

| 项目 | 保守基准 |
|---|---|
| 主图 | GIF，240×240，8–24 张，同一套全部动态 |
| 主图体积 | 先按后台提示；本项目默认按 500,000 bytes 检查 |
| 缩略图 | PNG，120×120，与主图一一对应，先按 50,000 bytes 检查 |
| 帧序列 | 由任务 SOP 锁定；常见任务为 4 帧 |
| 循环 | loop=0 |
| 透明度 | 透明背景、独立透明索引，解码后复核 |
| 配套图 | 读取通用微信规格和当前投稿页面，不凭空补齐 |

文字母版不是含义词。图中文字应保持统一字形和可读性；后台含义词须单独填写，通常为 1–4 个简体汉字且同套不重复。

不要把本地规格快照说成实时官方规范。微信后台提示、驳回理由和当前页面字段优先。
