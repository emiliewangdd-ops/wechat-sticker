# 动态表情审查清单

## 技术检查

- [ ] 主图编号连续，主图和缩略图编号一一对应；
- [ ] GIF 帧数与任务 SOP 一致；
- [ ] 每帧时长与基线一致；
- [ ] loop=0；
- [ ] disposal 与基线一致；
- [ ] 解码后的透明 alpha 与合成帧一致；
- [ ] 文字像素在每帧一致；
- [ ] 文字高度和位置符合锁定基线；
- [ ] 动作不越过动作框，源帧不贴边；
- [ ] 文件体积、尺寸和格式符合当前页面要求。

## 视觉审查

- [ ] 文字清晰，没有错字、额外笔画或黄色/彩色误描边；
- [ ] 角色身份和画风统一；
- [ ] 四帧动作含义清楚，动作差异真实；
- [ ] 角色、尾巴、耳朵、动作线没有裁切；
- [ ] 循环首尾衔接自然；
- [ ] 联系页和标注联系页均已查看；
- [ ] 用户明确确认后才标记视觉批准。

标注联系页中的红、黄、蓝、绿框是检查辅助线，不属于 GIF 内容。
